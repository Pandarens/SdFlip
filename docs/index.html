PDFs that turn like paper.

SdFlip is a free flipbook for the web. Real page curl, the sound of paper, spreads that line up, search and outline, and touch gestures that feel native on any phone. One script, no jQuery.

Features

Everything a catalog needs

Built for real-world PDFs: heavy photo catalogs, InDesign spreads, landscape decks and files with mixed page sizes.

Real page curl

The sheet bends in an arc with live shading and a cast shadow. Grab a corner and peel it.

Paper sounds

Rustle and landing are synthesized with Web Audio. No audio files, unlocked properly on iOS.

Native on phones

Swipe, pinch and double tap. Portrait shows one page, landscape a spread. Never traps scrolling.

Smart spreads

Double-width spreads are split and reassembled. Odd sizes are fitted, never stretched.

Search & outline

Thumbnails, the PDF outline and full-text search with highlighted snippets in a side panel.

Working links

Web, email and phone links from the PDF stay clickable, internal links jump to their page.

Fast and frugal

Prebuilt sheets, render pausing during flips and only nearby pages in memory.

Accessible & i18n

Keyboard shortcuts, screen reader announcements, focus return. English and Russian built in.

Inline mode

Or embed it in the page

The same viewer, living inside your layout. The height follows the document, so there are no empty bands.

  • Vertical swipes scroll the page, horizontal swipes flip
  • The mouse wheel scrolls the site, Ctrl + wheel zooms
  • Arrow keys work while the pointer is over the book
How it works

Paper, made of strips

No WebGL and no canvas animation loop. The curl is plain CSS 3D, so the GPU does the heavy lifting.

pdf.js renders the pages

The PDF is parsed in a web worker. Pages render to canvas at the exact size they are shown, sharper when you zoom in.

Virtual pages fix odd layouts

Double-width spreads become a left and a right page, other sizes get margins, and a blank page keeps spreads on the correct side.

The sheet is sliced into strips

The turning sheet is cut into 14–40 vertical strips nested inside each other. Each one turns a little more than its parent, so the page bends in an arc.

Light and shadow follow the angle

Each strip gets a gradient from the angle at its left edge to the angle at its right edge. Strips overlap by 2px, so there are no seams.

Sound is synthesized, not downloaded

Filtered noise is shaped into a rustle, a crackle and a landing slap, pre-rendered into a few buffers that play in sync with the animation.

The browser stays responsive

The next sheet is built while the screen is still, rendering pauses while a page flies, and pages far away are released from memory.

Install

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Pandarens/SdFlip@1.0.0/dist/sdflip.min.css">
<script src="https://cdn.jsdelivr.net/gh/Pandarens/SdFlip@1.0.0/dist/sdflip.min.js"></script>
npm install github:Pandarens/SdFlip
import 'sdflip/dist/sdflip.css';
import SdFlip from 'sdflip';

SdFlip.open('/files/catalog.pdf');

Grab sdflip-1.0.0.zip from the releases page and copy sdflip.min.js and sdflip.min.css to your site.

pdf.js 3.11 is loaded automatically from cdnjs the first time a PDF opens. See Hosting pdf.js to serve it yourself.

Usage

1. Links that open a lightbox

Any element with data-sdflip opens the viewer on click. The PDF comes from the attribute value or from href, so the link still works without JavaScript.

<a href="/files/catalog.pdf" data-sdflip data-sdf-title="Spring catalog">View catalog</a>

2. Open from JavaScript

const viewer = SdFlip.open({
  source: '/files/catalog.pdf',
  title: 'Spring catalog',
  page: 3,
  onFlip: (page) => console.log('now on page', page)
});

3. Embed inline

<div id="book"></div>
<script>
  SdFlip.inline('#book', { source: '/files/catalog.pdf' });
</script>

Content added later, for example by a SPA router? Call SdFlip.scan() after it is in the DOM. Elements are bound once.

JavaScript API

SdFlip

SdFlip.open(options | url)Opens a lightbox. Returns a viewer.
SdFlip.inline(container, options)Embeds a viewer into an element or selector. Returns a viewer.
SdFlip.cover(url, target, width)Draws the first page into an element. Returns a promise.
SdFlip.scan(root?)Binds new [data-sdflip] elements. Runs on page load.
SdFlip.defaultsDefault options, editable.
SdFlip.localesUI strings by language.

next(), prev()Flip forward or back with animation.
goTo(page)Go to a page, animating the last sheet.
page()Current page number (left page of a spread).
setZoom(factor)Zoom from 1 to maxZoom.
toggleSound(), toggleFullscreen()Same as the toolbar buttons.
download(), print()Same as the toolbar buttons.
close()Closes a lightbox with a fade, or destroys an inline viewer.
destroy()Removes the viewer and frees memory immediately.

Events

SdFlip.open({
  source: 'catalog.pdf',
  onReady: (viewer) => {},              // first pages are on screen
  onFlip: (page, direction) => {},      // after every turn; direction is 1 or -1
  onClose: (viewer) => {},
  onError: (error, viewer) => {}        // the PDF could not be opened
});

Theming

The viewer is styled with CSS custom properties on .sdf-root.

.sdf-root {
  --sdf-bg: #0d0f13;       /* lightbox backdrop */
  --sdf-panel: #171a20;    /* header, toolbar, inline background */
  --sdf-panel2: #212730;   /* hover, inputs */
  --sdf-line: #2e3744;     /* borders */
  --sdf-fg: #e9edf3;       /* text and icons */
  --sdf-muted: #97a1b0;    /* secondary text */
  --sdf-accent: #5b5bf6;   /* active buttons, progress, highlights */
  --sdf-paper: #fff;       /* page color behind the PDF */
}

Localization

English and Russian ship with the library. Add a language once and every viewer picks it up when <html lang> matches. Missing keys fall back to English; see SdFlip.locales.en for the full list.

SdFlip.locales.de = {
  download: 'PDF herunterladen',
  close: 'Schließen (Esc)',
  pageOf: 'Seite {page} von {total}'
};

SdFlip.open({ source: 'katalog.pdf', lang: 'de' });

Hosting pdf.js

To avoid the CDN, copy pdf.min.js and pdf.worker.min.js (pdf.js 3.x) to your server and point SdFlip at them. window.SdFlipConfig works even if it is defined before the library loads.

<script>
  window.SdFlipConfig = {
    pdfjs: '/vendor/pdf.min.js',
    pdfjsWorker: '/vendor/pdf.worker.min.js'
  };
</script>
<script src="/vendor/sdflip.min.js"></script>

PDFs from another domain need CORS headers. Opening an HTML page straight from disk (file://) blocks PDF loading in every browser; serve the folder over HTTP, for example with npx serve.

Browser support

Chrome, Edge, Firefox and Safari released in the last few years, on desktop and mobile, including iOS Safari. SdFlip respects prefers-reduced-motion.
