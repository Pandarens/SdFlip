# Changelog

## 1.0.0 — 2026-11-02

First public release.

- Page curl built from nested CSS 3D strips with angle-based shading, cast shadow and a corner that lifts on hover.
- Paper sounds synthesized with Web Audio and pre-rendered in the background; `soundUrl` for your own file.
- Lightbox and inline modes, `data-sdflip` links, `SdFlip.cover()` thumbnails.
- Double-width spreads split into pages, odd page sizes fitted with margins, blank page insertion to keep spreads aligned.
- Touch gestures: swipe, pinch, double tap; automatic single or double layout.
- Thumbnails, PDF outline, full-text search, clickable PDF links, download, print, fullscreen.
- Flip queue for rapid clicks, prebuilt sheets, render pausing during animation, memory limited to nearby pages.
- Keyboard shortcuts, screen reader announcements, focus return, reduced motion.
- Localization with English and Russian built in, `lang` and `strings` options.
